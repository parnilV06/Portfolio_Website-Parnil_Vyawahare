# Parnil Vyawahare portfolio

A responsive single-page portfolio for Parnil Vyawahare. The homepage is built with React, TypeScript, Vite, and Tailwind CSS. It preserves the tactile portfolio keyboard and physical project archive while establishing Parnil’s matte-black, off-white, and cyan design direction.

## Run locally

```bash
pnpm install
pnpm dev
```

Production checks:

```bash
pnpm typecheck
pnpm build
pnpm test
```

Contact email and location are defined near the top of `client/pages/Index.tsx`; resume files and social URLs remain intentionally unconfigured until real destinations are supplied.
